# Historical validation from the previous repository

The predecessor was tested on a Ryzen 7 5700X / RTX 4060 Ti desktop and a Dell Latitude 5420 / Intel Iris Xe laptop, both running Ubuntu 26.04.1 with GNOME Wayland and Conky through XWayland. Its 1.1.0 evidence is historical; the new repository starts a separate 0.1.0 release sequence.

Checks covered hardware capability discovery, dynamic disk mounts, optional languages/software, GPU-unit fidelity, process tops, weather from a manual city, calendar alignment, display scaling and independent cards. Source files and personal config/cache/state were separated. Later development added the bounded diagnostic/history/task/context tools described by the current guides.

The [screen capture record](screenshots.md) includes physical resolution and desktop scale. [Current testing](testing.md) describes the expanded source/CI/native verification layers. Historical renders cannot establish present compatibility on an untested desktop or driver.

The complete old source/history and operational evidence were preserved privately before retiring its public remote. No private administrative records are distributed in this repository.
